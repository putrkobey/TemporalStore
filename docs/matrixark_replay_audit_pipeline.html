MatrixArk Replay And Audit Pipeline

Replay and audit are wired for MatrixArk context retrieval. Retrieval writes context_pack_audit, operational and access actions write matrixark_audit_log, and matrixark_replay can return the persisted record stream needed to reconstruct selected evidence.

Why This Matters

Replay and audit answer what MatrixArk returned, why those refs were selected, what was dropped, which token budget and retrieval policy were used, and which account, tenant, user, session, or API key performed the action.
