LOCOMO Benchmark Workflow: TemporalStore vs Python Memory

This walkthrough shows how LOCOMO conversations become MatrixArk context records, how retrieval builds a ContextPack, and what differs when the same pipeline uses Python memory versus TemporalStore as the storage boundary.

What LOCOMO Tests

Single-hop
One turn contains the answer.
Multi-hop
The answer requires combining multiple turns or sessions.
Temporal
Questions depend on dates, before/after, or current/latest state.
Updates
Newer facts supersede older facts while old evidence remains replayable.

End-To-End Workflow

1. LoadLOCOMO JSON sessions and QA.
2. BatchSession turns become message batches.
3. ExtractOne pass emits events, entities, summaries, indexes, segments.
4. StorePython memory or TemporalStore record log.
5. RetrieveDense, sparse, keyword, time-decay recall.
6. PackQuestion-type token-budgeted ContextPack.
