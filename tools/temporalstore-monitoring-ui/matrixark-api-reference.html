MatrixArk

API And Schema Reference

Operations Console Agent Envelope

Boundary

Agents send simple evidence. MatrixArk always extracts. TemporalStore serves the internal model.

Public Caller Model

messages + scope + metadata + optional hook evidence
-> MatrixArk extraction
-> ContextPack returned to agent

Hidden Internal Model

  • ContextEvent, ContextEntity, ContextIndex
  • ContextNode, ContextChildRef, ContextSummary
  • ContextEmbedding, ContextCompressionEvent, ContextPackAudit

Public APIs

HTTP endpoints are the production contract; MCP tools mirror the same shapes for local and agent integrations.

POST /v1/context/ingest

Ingest one message, tool output, business event, or resource description.

{
  "messages": [{"role": "user", "content": "Alice approved the GPU request."}],
  "scope": {"user_id": "alice", "session_id": "thread-gpu", "team": "infra_team"},
  "metadata": {"source": "cursor"},
  "agent_hook": {"hook_type": "before_llm", "auto_captured": true}
}

POST /v1/context/retrieve

Return a token-budgeted ContextPack for a raw query.

{
  "query": "What GPU approvals are current?",
  "scope": {"session_id": "thread-gpu", "team": "infra_team"},
  "max_context_tokens": 10000,
  "hints": {"retrieval_timeout_ms": 5000}
}

POST /v1/context/feedback

Capture confirmations, corrections, accepted refs, rejected refs, and final answer feedback.

{
  "messages": [{"role": "user", "content": "Yes, that answer is correct."}],
  "context_pack_id": "pack-thread-gpu",
  "accepted_refs": [{"ref_type": "event", "ref_hash": 52001}]
}

Batch, Stream, Resource, Audit, Replay

  • /v1/context/batch_ingest: per-row success and errors
  • /v1/context/stream_ingest: stream, partition, offset, payload
  • /v1/context/resource: raw URI, type, parsed chunks, embeddings
  • /v1/context/audit/{pack}: selected, blocked, dropped refs
  • /v1/context/replay/{pack}: replayable evidence
