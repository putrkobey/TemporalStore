Connection

The admin key is held in sessionStorage for this tab only and is sent as Authorization: Bearer <key>. It is never written into the page source or persisted to disk. It must carry the admin:api_key scope (usage reads also accept admin:audit).

No key yet?

This page cannot mint the first one — creating a key is itself an admin-scoped call. Run this wherever the gateway reads its keystore, then paste what it prints:

python3 tools/matrixark_provision_api_key.py \
  --tenant-id tenantA --account-id acct_local \
  --scopes admin:api_key,admin:audit,portal:read \
  --store "$MATRIXARK_API_KEYS_HASHED_FILE"

The key is printed once and only its hash is stored, so copy it before the terminal scrolls. --scopes is not optional in practice: left off, the tool mints the four context:* scopes, and a key carrying those is refused by this page with no hint as to why.

Create a key

Calls POST /api/admin/create_api_key (tool matrixark_admin_create_api_key). The plaintext key is returned once — MatrixArk stores only its hash.

Connect above to load the scope catalogue.

Keys

Calls POST /api/admin/list_api_keys. Rotate mints a replacement carrying the same scopes/identity (/api/admin/rotate_api_key); revoke marks a key inactive (/api/admin/revoke_api_key).

Policy overrides

Who in this tenant has settings of their own. Calls GET /v1/admin/policy?overrides=1. The tenant comes from your key, so this lists your tenant and nobody else's. A row means that identity resolves some knob differently from the deployment default — the thing you cannot otherwise find without already knowing which id to ask about.

identitylevelsettings

Live edge usage

Calls GET /v1/admin/api_key_usage on the gateway — the in-process per-key counter (keys shown hashed). Populated only in enforced mode.

Audit trail

Calls GET /v1/admin/audit — key management and refusals for your tenant, newest first. Needs a key carrying admin:audit. Loaded when you ask for it and never on a timer: the read walks the record log, and a panel refreshing itself would put that walk on a schedule for as long as this tab stayed open.
