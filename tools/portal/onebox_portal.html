Whether it is answering

Under load this gateway stops retrieving and answers every retrieve with an empty pack in about 100 milliseconds — still HTTP 200, and faster than doing the work, so nothing else on this page or any latency chart would tell you. What decides recall

The three caps that bound a retrieve, and which of them was doing the cutting. Raising the others changed nothing in that measurement. Each shows the value in force and the build default it fell back to, so an override is visible as one.

Enter an admin key to read the limits.

Returning everything

A store small enough to fit the answer's budget does not need ranking to choose for it. Measured on this build: eighty short facts, one question, an 8000-token budget — forty came back. Eighty facts of that length is about a thousand tokens, so the budget was never what cut it. With return_all_candidates on, seventy-nine came back.

Enter an admin key to read the policy.
